Calendar timezone
Fixed manual offset. IBIS treats imported lesson times as GMT and currently adds two hours. When the clocks change, switch this setting to GMT+1 and IBIS will recalculate the stored calendar display.
The original ICS value is retained in the imported calendar source. The lesson register, Teaching Cockpit and Next Actions use the adjusted IBIS teaching time.
ICS student naming
Calendar name is authoritative. IBIS takes the student name from the ICS event title after removing the “- Preply Lesson” suffix. If needed, edit the student directly in the lesson register.
Import rules
What IBIS reads: date, time, duration, summary, UID, status, description and location.
What IBIS does not assume: recurring lessons, automatic student identity, or that an event should overwrite a lesson record.

Google Calendar · Incremental Sync v3
Incremental Sync v3 bootstraps a Google sync cursor, then checks only calendar changes. Changes are queued for preview; applying remains explicit. Cancellations and uncertain matches are flagged, not silently merged. Lesson IDs, preparation, reports and historical evidence must be preserved.
